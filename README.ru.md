# Minghe iOS

[简体中文](README.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Français](README.fr.md) · [Русский](README.ru.md) · [Español](README.es.md) · [Deutsch](README.de.md)

Minghe — клиент голосовой связи SIP для самостоятельно размещаемого сервера Minghe. В iOS используется интерфейс Android на React и TypeScript с клавиатурой набора, журналом вызовов, настройками оформления и восемью языками. Capacitor 8.4.1 связывает интерфейс с Linphone 5.4.129, CallKit и связкой ключей.

## Сборка из исходного кода

Установите Xcode и Node.js 22.12 или новее на macOS и выполните команды из корня репозитория.

```sh
npm --prefix web ci
npm --prefix web run build
```

Откройте `Minghe.xcodeproj` и выберите схему `Minghe`. Для установки на устройство выберите команду разработчиков в **Signing & Capabilities**. Поддерживается iOS 17 и новее. После изменений в `web/src` пересоберите веб-ресурсы.

## Подключение и вызовы

В разделе **Аккаунт** укажите адрес сервера, добавочный номер и пароль SIP, затем подключитесь. По умолчанию используются порт TLS 5061, Digest SHA-256 и SDES-SRTP. Включайте MD5 только по требованию сервера. Для ретранслятора ZRTP выберите ZRTP и сравните код SAS с собеседником. В режиме SDES-SRTP сервер может расшифровывать и повторно шифровать медиапоток.

Для частного сертификата вставьте PEM от администратора или проверьте отображаемый отпечаток SHA-256 по независимому каналу перед подтверждением. Адрес сервера должен соответствовать сертификату. Сохранённые пароли хранятся в связке ключей.

## Уведомления Bark и заблокированный экран

Установите Bark, разрешите уведомления и настройте добавочный номер на своём сервере. В Minghe включите **Сохранить пароль** и **Уведомления Bark**, затем подключитесь. Сервер удерживает входящий вызов до 30 секунд, пока получатель не в сети. Нажмите уведомление, чтобы открыть Minghe и принять ожидающий вызов через CallKit. Установленный вызов продолжается при блокировке экрана.

Для Minghe не требуется ключ APNs или официальный сервер-посредник. Уведомление доставляет Bark. Вызов появляется после открытия уведомления и успешной регистрации SIP.

Добавьте на сервере Minghe следующую конфигурацию для добавочного номера 1002. Передайте ключ устройства Bark процессу сервера через указанную переменную окружения.

```toml
[bark."1002"]
endpoint = "https://api.day.app/push"
device_key_env = "MINGHE_BARK_1002_KEY"
```
